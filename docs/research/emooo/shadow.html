05FAQ

常见问题。

Q1支持哪些客户端?+

可接入支持自定义端点的客户端。Codex 使用 Responses API，Claude Code 使用 Messages API；请在 API 密钥页面选择目标客户端与兼容模型。模型出现在目录中，不代表所有工具调用或多模态能力都已适配。

Q2怎么计费?缓存怎么算?+

文本模型通常按实际 Token 用量与适用价格计费，缓存与推理用量依模型规则结算；图片和视频可能按张、秒或次计费。充值到账额度以确认页为准，使用记录可逐笔查询与导出。

Q3上游故障会影响我吗?+

调度会依据上游状态，在权限、模型、协议和成本允许且存在合格备用时避让异常通道。已开始输出的流不会自动拼接另一条线路；没有可用备用时会返回错误，可凭请求编号联系管理员。

Q4我的数据安全吗?+

本站使用 HTTPS。为用量核对、排障和安全审计，会记录必要的请求信息；启用相应审计规则时，请求正文也可能被留存并由有权限的管理员查看。留存范围与期限依站点配置执行，请勿提交不必要的敏感信息。
